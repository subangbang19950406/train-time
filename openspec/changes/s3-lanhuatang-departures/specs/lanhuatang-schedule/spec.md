## Purpose

以兰花塘站官方站牌为锚点，保存 S3 往高家冲与往南京南两个方向的逐班时刻及工作日 / 非工作日日历。

## ADDED Requirements

### Requirement: 双向时刻真源均来自兰花塘站牌

系统 MUST 分别保存「往高家冲」「往南京南」两套逐班时刻，各含工作日与非工作日。往高家冲时刻 MUST NOT 包含仅终到刘村的短交路班次。

#### Scenario: 往高家冲首末班与站牌一致

- **WHEN** 使用任一日历查询往高家冲方向
- **THEN** 兰花塘锚点首班 MUST 为 06:37
- **AND** 末班 MUST 为 22:37

#### Scenario: 往南京南首末班与站牌一致

- **WHEN** 使用任一日历查询往南京南方向
- **THEN** 兰花塘锚点首班 MUST 为 06:11
- **AND** 末班 MUST 为 22:11

### Requirement: 各站相对兰花塘的固定时差

系统 MUST 为每个方向维护各站相对兰花塘锚点时刻的分钟偏移（`offsetFromLanhuatang`），用于由锚点推算任意站时刻。

#### Scenario: 首班时差对拍

- **WHEN** 往高家冲方向锚点为 06:37
- **THEN** 油坊桥推算时刻 MUST 为 06:12
- **AND** 刘村 MUST 为 06:25
- **AND** 高家冲 MUST 为 06:49

### Requirement: 工作日与非工作日两套表

系统 MUST 按当前选中日历只使用对应方向的那套时刻列表，不得混用。

#### Scenario: 手切日历立即换表

- **WHEN** 用户把日历从工作日改为非工作日
- **THEN** 班次列表 MUST 立刻使用该日历的时刻列表重算

### Requirement: 日历默认按星期几

系统 MUST 在周一至周五默认工作日、周六日默认非工作日。用户 MUST 能手动切换；系统不负责法定假 / 调休识别。

#### Scenario: 周六默认非工作日

- **WHEN** 本地日期为周六且用户未手切
- **THEN** 系统 MUST 使用非工作日时刻表
