## Purpose

在手机上以紧凑布局展示查询条件与班次列表，便于通勤场景快速查阅。

## ADDED Requirements

### Requirement: 紧凑查询条一行展示

方向、上车点、下车点、日历 MUST 在视觉上尽量紧凑；上车 / 下车 / 日历 MUST 合并为同一行查询条，方向单独一行小尺寸分段控件。

#### Scenario: 查询条布局

- **WHEN** 用户在手机竖屏查看页面
- **THEN** 上车点、下车点、日历控件 MUST 处于同一行容器内
- **AND** 方向控件 MUST 不占独立大 panel

### Requirement: 方向与日历使用分段控件而非大按钮

方向与日历 MUST 使用 radio + label 的小型胶囊分段，而非全宽按钮组。

#### Scenario: 日历手切

- **WHEN** 用户点击「休」
- **THEN** 日历 MUST 切换为非工作日且列表立即更新

### Requirement: 站点使用自定义下拉

上车点与下车点 MUST 使用自定义下拉（触发条 + 自绘选项列表），以统一移动端样式；选项列表 MUST 标明当前选中项。

#### Scenario: 打开站点菜单

- **WHEN** 用户点击上车点触发条
- **THEN** 系统 MUST 展示该方向可选上车站列表
- **AND** 当前选中站 MUST 有选中样式

### Requirement: 班次列表信息

每一班 MUST 展示：约上车时刻、到达下车点时刻、等待时间（「还有 N 分钟」或「即将发车」）。最近一班 MUST 有视觉强调。

#### Scenario: 等待文案

- **WHEN** 下一班还有 4 分钟
- **THEN** 等待区 MUST 显示「还有 4 分钟」（「还有」为小号灰色前缀）

### Requirement: 免责声明

页脚 MUST 说明数据来自兰花塘站牌、仅供参考，并注明往高家冲不含刘村短交路。

#### Scenario: 页脚可见说明

- **WHEN** 用户滚动至页面底部
- **THEN** MUST 可见数据来源与刘村短交路免责说明
